## Project Summary
An ultra-modern, high-end landing page for HomeTech Chemical, a premier manufacturer of elite construction chemicals. The site features a "rich choice" aesthetic with deep obsidian backgrounds, liquid gold accents, and sophisticated 3D industrial visuals, designed to convey architectural mastery and unyielding trust.

## Tech Stack
- Framework: Next.js 15 (App Router)
- Styling: Tailwind CSS 4
- Icons: Lucide React
- Fonts: Syne (Display), Plus Jakarta Sans (Sans)
- Components: High-performance React components with glassmorphism and 3D effects.

## Architecture
- `src/app/page.tsx`: Main entry point assembling the premium sections.
- `src/components/sections/`: Modular landing page sections (Hero, About, Portfolio, etc.).
- `src/app/globals.css`: Theme configuration for the obsidian/gold rich aesthetic.

## User Preferences
- Ultra-modern "rich choices" looking aesthetic.
- High-end industrial imagery with 3D elements.
- Deep, sophisticated color palette (Obsidian, Gold, Emerald).
- Editorial-style typography.

## Project Guidelines
- Use functional components with named exports where possible.
- Maintain a consistent "Glassmorphism" effect across cards.
- Prioritize high-impact animations for section reveals.
- Keep "use client" usage minimal to ensure fast performance.

## Common Patterns
- **Liquid Gold Gradients:** Used for primary headlines and focus elements.
- **Glassmorphism:** Semi-transparent containers with heavy blur and subtle borders.
- **3D Card Shadows:** Deep, multi-layered shadows for a tactile feel.
- **Syne Font:** Used for bold, architectural display text.
- **Icon Accentuation:** Icons wrapped in glass-bordered containers with gold glows.
